# Building the Standalone Executable (.exe)

This guide explains how to package the **Inventory Management System (v3.0)** into a single standalone Windows executable (`InventoryManager.exe`) using PyInstaller.

---

## 1. Prerequisites

1. **Python 3.12** installed and on your system `PATH`.
2. **MySQL / MariaDB** (e.g. via XAMPP, WAMP, or standalone MySQL service) installed and running.
3. Install project dependencies and PyInstaller:
   ```bash
   pip install -r requirements.txt
   pip install pyinstaller
   ```

---

## 2. One-Command Build

From the root project directory (`PROJECT_INVENTORY - v3`), execute:

```bash
pyinstaller --noconfirm --onefile --windowed --name InventoryManager --icon images/app_icon.ico --collect-all customtkinter --add-data "images;images" main.py
```

### Command Flags Breakdown:
- `--noconfirm`: Overwrites previous build artifacts without prompting.
- `--onefile`: Bundles the entire application, Python runtime, and all libraries into a single `.exe`.
- `--windowed`: Suppresses the background console window (clean GUI experience).
- `--name InventoryManager`: Names the output binary `InventoryManager.exe`.
- `--icon images/app_icon.ico`: Embeds the high-resolution store icon into the executable.
- `--collect-all customtkinter`: Packages CustomTkinter themes, fonts, and JSON asset dictionaries into the bundle.
- `--add-data "images;images"`: Bundles logos, banners, and default icons into the internal temp directory.
- `main.py`: Application entry point.

The generated executable will be placed in the `dist/` folder:
```
dist/InventoryManager.exe
```

---

## 3. How File Paths Work (Frozen vs Development)

The application handles storage transparently using the unified path helper in `config.py` (`get_path()`):

1. **Read-Only Bundled Assets (Images, Icons)**:
   - Extracted to PyInstaller's temporary execution directory (`sys._MEIPASS`).
   - Resolved automatically via `config.IMAGE_DIR`.
2. **Writable Application Data**:
   - Stored in `%LOCALAPPDATA%\InventoryManager\` when frozen (or project directory during development).
   - Saved files include:
     - `db_config.json` (MySQL host, port, username, password)
     - `bill/` (Saved text customer bills and purchase orders)
     - `backups/` (Full timestamped ZIP database backups)
     - `images/products/` (Uploaded product photographs)

---

## 4. Deployment Checklist

- **Files needed next to the .exe**: **NONE**. The executable is 100% self-contained.
- **MySQL Server**: MySQL must be running (e.g. start MySQL in the XAMPP Control Panel).
- **First Launch**:
  - The application automatically connects to MySQL and executes `setup_database()`, creating all 12 tables and demo records.
  - If MySQL has a custom password or non-standard port, the app displays the **"Connect to MySQL"** dialog, tests the connection, and saves the configuration to `%LOCALAPPDATA%\InventoryManager\db_config.json`.

---
**Note:** `build/`, `dist/` and the `.spec` file are *generated by PyInstaller* (the `.html` inside `build/` is only a module report). Never submit them - only submit the source files.
